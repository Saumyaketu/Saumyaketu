### 2. **YouTube Clone & Watch Party Platform**
A full-featured video streaming platform with real-time collaboration features

**Key Features:**
- **Video Streaming Platform** — Upload, watch, like, comment, and manage content
- **Real-Time Watch Parties** — Synchronized playback with Socket.io for multiple users
- **WebRTC Video Calling** — Peer-to-peer video chat with screen sharing & recording
- **Secure Authentication** — Google OAuth + Phone OTP via Firebase
- **Payment Integration** — Razorpay for subscription management (Bronze, Silver, Gold tiers)
- **Advanced Features** — Multilingual comments, geolocation tagging, PWA support
- **Gesture Controls** — Tap-based player controls for seamless UX
- **Offline Downloads** — Save videos for later viewing

**Tech Stack:** 
- Frontend: Next.js, React 19, Tailwind CSS, Radix UI, Socket.io-client
- Backend: Node.js, Express, MongoDB, Socket.io
- Services: Firebase, Cloudinary, Razorpay

**What I learned:** Complex real-time systems, WebRTC signaling, payment integration, scalable architecture
